# Griphin_first
🎲 Random Number Generator

A simple and interactive Random Number Generator built with HTML, CSS, and JavaScript.

Click the button and a new random number is generated instantly.

🚀 Features

* 🎯 Generates a random number on button click
* ⚡ Instant result
* 🖥️ Simple and clean interface
* 📱 Responsive design
* 🧠 Built using basic JavaScript concepts

🛠️ Technologies Used

* HTML — Structure
* CSS — Styling
* JavaScript — Random number generation and button interaction

📂 Project Structure

random-number-generator/
│
├── index.html
├── style.css
├── script.js
└── README.md

⚙️ How It Works

When the user clicks the button, JavaScript generates a random number using:

Math.random()

The generated value is then displayed on the webpage.

▶️ How to Run

1. Clone the repository:

git clone YOUR_REPOSITORY_URL

2. Open the project folder.
3. Open index.html in your browser.

That’s it! 🎉

📸 Preview

Click the Generate button to generate a new random number.
